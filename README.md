# 🏦 Meezan Bank AI Advisor

An intelligent AI-powered financial assistant designed for Meezan Bank, capable of answering queries, fetching live data, and guiding users through banking services using advanced Agentic workflows.

## 🚀 Features

- ** AI Agent Architecture:** Uses Groq (Llama 3) with Function Calling to intelligently decide when to use tools.
- **️ Multi-Tool Support:** 
  - Live USD/PKR Exchange Rates
  - Real-time Gold Rates
  - Prayer Times (Namaz Auqaat)
  - Account Balance Simulation
- **🖼️ Dynamic Image Display:** Automatically shows relevant images (accounts, rates, etc.) based on the user's query.
- **🕌 Shariah-Compliant:** tailored specifically for Islamic banking context.
- **🎨 Professional UI:** Built with Streamlit, featuring Meezan Bank branding and responsive design.

## 🛠️ Tech Stack

- **Python 3.10+**
- **Streamlit** (Frontend)
- **Groq API** (LLM & Tool Calling)
- **Git & GitHub** (Version Control)

## 📦 How to Run Locally

1. Clone the repository:
```bash

   cd my-ai-assignment
```

2. Install dependencies:
```bash

```

4. 4. Run the app:
